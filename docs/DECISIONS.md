## Backend-A (Foundation, PRD Phases 1–2)

| # | Topic | Decision | Why |
| --- | --- | --- | --- |
| A1 | Local MySQL | `npm run db:local` uses `mysql-memory-server` only to download the official MySQL **8.4.9** macOS arm64 binary (cached in `$TMPDIR/mysqlmsn/binaries`), then runs `mysqld` itself with a persistent data dir `.mysql-data/data` on `127.0.0.1:3307`, user `root`, no password. `--ephemeral` flag falls back to the library's throwaway DB. | The library only supports throwaway databases; persistent data survives restarts. 8.4 LTS ≥ 8.0.16, so CHECK constraints are enforced. |
| A2 | Data dir path | `.mysql-data/data`, not `.mysql-data` itself. | mysqld fails with "Can't create UNDO tablespace … './undo_001' already exists" when the datadir's own name starts with a dot. |
| A3 | Test database | Integration tests reset + seed a separate `dental_test` DB on the same server (`TEST_DATABASE_URL`, default: `DATABASE_URL` with the db renamed). They refuse non-local hosts and DB names without "test". | Tests never clobber dev data. |
| A4 | `db:reset` on remote hosts | Allowed (PRD Phase 11 needs it on the hosted DB) but prints the target and requires `--yes` for any non-localhost host: `DATABASE_URL="…" npm run db:reset -- --yes`. Shell env vars win over `.env.local`. | Prevents wiping the demo DB by accident. |
| A5 | Transaction isolation | `withTransaction` runs at **READ COMMITTED**. | With row locks (Rule 9) serializing writers, READ COMMITTED guarantees the overlap SELECT sees rows committed by the previous lock holder. Under REPEATABLE READ the snapshot could predate the lock (e.g. Rule 10 trying dentist 2 after dentist 1). |
| A6 | Session time zone | Pool sets `timezone: '+08:00'`, `dateStrings: true`, and runs `SET time_zone = '+08:00'` on every new connection; local mysqld also starts with `--default-time-zone=+08:00`. | NF08: `NOW()` (Rule 11 `requested_at = NOW()`) is Manila time even on a UTC host. A fixed offset is exact because Manila has no DST and avoids needing tz tables on Aiven. |
| A7 | Named placeholders | Pool has `namedPlaceholders: true`, so Listing 3.1-style `:appointment_id` works; `?` still works with array params. | Lets the SQL match the paper's listings. |
| A8 | Aiven SSL | `ssl-mode=REQUIRED` (or `sslmode=require`, `ssl=true`) turns TLS on. If `DATABASE_CA_CERT` (PEM) is set the cert is verified; otherwise the connection is encrypted without CA verification. | Aiven uses a per-project CA; the PRD's URL-only setup would fail with strict verification. Set `DATABASE_CA_CERT` on Vercel to harden. |
| A9 | Contact numbers | `normalizeContact` strips spaces, dashes, parentheses, dots; `+63`/`63` → `0`. Valid results: PH mobile `09` + 9 digits (11), landline with area code `0[2-8]` + 7–8 digits (9–10), or local landline `[2-8]` + 6–7 digits (7–8). Everything else → `null` (validation error). Stored digits-only, shown `0917 555 0101` / `(02) 8123 4567`. | PRD asks only for mobile examples; walk-ins may give a landline. A 10-digit number starting `09` (a mistyped mobile) is still rejected. |
| A10 | Past check | `isInPast(date, start)` is true when start ≤ now (Manila). `hasStarted` = same test, used for Rule 7 (`attended`/`no-show` allowed once start time is reached). | Rule 3 says "later than now"; Rule 5 drops starts "at or before" now. |
| A11 | Seed: walk-in timestamps | Walk-ins get `requested_at` = 15 min before the start on the same day, and `reminder_sent_at` NULL. Patients without email also get NULL reminders. All other past rows that were scheduled: `requested_at` 2–5 days before, `reminder_sent_at` 09:00 the day before. | A walk-in booked days ahead (or reminded the day before it existed) would look wrong at the defense; Rule 8 never emails patients without an address. |
| A12 | Seed placement | Extra October rows sit on Oct 1–8 (Mon–Sat) only; Oct 9 onward stays open except the Table 3.6 rows (Oct 12 attended/no-show, Oct 19 scheduled). Reyes always uses Chair 1, Lim Chair 2. The seed asserts no dentist/chair/patient collisions and the Table 3.22 totals before inserting. | PRD Open Question #3; keeps demo days free. |

| A14 | Seed staff password | `SEED_STAFF_PASSWORD` env, default `ClinicDemo2026!`, bcrypt cost 12. | Change it before seeding the public demo DB. |
| A15 | Session | jose HS256 JWT in cookie `session`: httpOnly, SameSite=Lax, Secure when `NODE_ENV=production`, path `/`, 8 h. Payload: `sub` = user_id, `name`, `email`. Not re-checked against the DB per request (single staff role; logout clears the cookie). | PLAN fixed decision; edge-safe for middleware. |
